# 4sou9.github.io 制作スキル

Astro の静的サイト。GitHub Pages のユーザーサイトとして `main` への push で自動デプロイされる。
現在のページは入口 (`/`) と 404 の2枚だけ。**JS ランタイムは1バイトも配信していない** — この性質を壊さないこと。

## 0. 見た目の芯

淡い紙 `#eceae4` に墨 `#16161a`。余白が主役で、線は髪の毛のように細い1本だけ。
中央よりやや外に、レイマーチで解いたジャイロイド格子の球が1つ浮かぶ。
階調は**必ず5段以下**に量子化し、8×8 の Bayer 順序ディザで刷る。連続階調は禁止 — 印刷物の網点に見せることが全体の質感を決めている。

色を足さない。派手な動きを足さない。要素を足さない。**引くことでしか良くならない画面**として扱う。

## 1. ファイルの地図

| 場所 | 役割 |
|---|---|
| `src/layouts/Screen.astro` | 画面の全て。head のメタ、CSS、シェーダー、キャンバス制御 |
| `src/pages/*.astro` | 文言だけ。15行前後に収める |
| `tools/make-icons.mjs` | ファビコン一式と `favicon.ico` を生成 |
| `tools/make-og.mjs` | OG画像。シェーダーを CPU に移植して焼く |
| `public/` | 生成済みの素材。ここに手で画像を置かない |

`npm run assets` で素材を作り直す。ビルド時には走らないので、**文言や構図を変えたら必ず実行する**。

## 2. ページの足し方

`Screen` に文言を渡すだけ。レイアウトを触る必要はほぼない。

```astro
---
import Screen from '../layouts/Screen.astro';
---
<Screen title="…" description="…" path="/…" body="…">
  <h1 class="display">Nothing<br /><em>in&nbsp;Particular</em></h1>
</Screen>
```

- `body` は**スロットではなくプロパティ**。日本語フォントの使用文字を自動で集めるため。スロットに日本語を書くと字が欠ける。
- 見出しは欧文セリフ体 (Instrument Serif)。2行目を `<em>` にしてイタリックで受ける。
- `mode="fault"` でシェーダーが断層モードになる。404 が使っている。
- 検索避けが要るページは `noindex` を渡す。canonical の代わりに robots メタが出る。

## 3. シェーダーの規約

`Screen.astro` の `FRAG` が全て。WebGL2 の GLSL ES 3.00。

- `map()` は球と多層ジャイロイドの `max()` 交差。戻り値に安全係数 `* 0.5` を掛けている — **周波数を上げたらこの係数を下げる**。上げるとレイが表面を突き抜けて穴だらけになる。
- 紙は輝度 `1.0` 固定。ここに濃淡を入れるとディザが画面全体に食いつき、市松模様の地になる。ワッシュとビネットは**量子化の後**に乗算で掛けること。
- 粒子ノイズは `smoothstep(1., 0.86, lum)` で墨のある所だけに限定する。
- 新しいパラメータは uniform で渡し、JS 側の `u` と `build()` の両方に足す。片方だけだとコンテキスト復帰時に消える。

### 触ってはいけない仕掛け

- **コンテキスト消失の復帰**: `build()` は再実行できる形になっている。GL オブジェクトを `build()` の外で作らないこと。
- **解像度の自動調整**: 毎秒 fps を測り 0.55〜1.0 倍で解像度を動かす。表示はしないが計測は続いている。
- **ディザの升目**: `uPix` は devicePixelRatio に合わせてあり、これがずれると網点が濁る。

## 4. タイポグラフィ

- 見出しは欧文、本文は日本語。この対比が現在の紙面の骨格。
- 明朝には本物のイタリックがない。日本語で強調するなら字間を開ける。
- 日本語フォントは**使用文字だけ**を要求する。Google Fonts の `text` パラメータはリクエスト全体に効くので、欧文と日本語で `<link>` を2本に分けてある。統合しないこと。
- 余白は論理プロパティ (`margin-block-start` / `max-inline-size`) で書く。縦組みを試すときに書き直さずに済む。

## 5. 素材

- マークは紙色の円に墨の裂け目2本。16px で潰れないことが唯一の条件。
- OG画像はシェーダーと**同じ数式**を JS で解いて焼く。見た目がサイトとずれないための仕組みなので、別の絵を描いて置き換えない。
- 半分の解像度で計算して最近傍で2倍にしている。網点を2px角に保つため。
- 文字は librsvg の縦書きが当てにならないので、縦組みが要るなら1文字ずつ座標を置く。

## 6. 追加する前に確認すること

1. その要素は**引けないか**。この画面は要素が少ないほど良くなる。
2. JS ランタイムが増えていないか。`dist/_astro/` が生まれたら設計を間違えている。
3. 文言を変えたら `npm run assets` を走らせたか。
4. 横長と縦長の両方で見たか。構図は縦横比で切り替わる。
5. `dist` が数百KBを超えていないか。素材の置き忘れを疑う。
